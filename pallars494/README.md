# Simulador de derramas · Pallars 494

Aplicación de simulación en desarrollo para la Comunidad de Propietarios de C/ Pallars 494, Barcelona. Los importes iniciales son ficticios y no constituyen una derrama aprobada.

Abre `app/Pallars494_derrames_v2_6.html` en el navegador. Funciona sin conexión. El almacenamiento local depende del navegador: exporta los escenarios JSON para mantener copias seguras. No subas escenarios, información personal ni documentos privados al repositorio.

Pruebas de referencia (requieren Node.js): desde esta carpeta, ejecuta `node --test tests/fase1.test.cjs tests/fase2.test.cjs tests/fase3.test.cjs tests/fase4.test.cjs tests/fase5.test.cjs tests/fase6.test.cjs`. Véase `CHANGELOG.md` para cambios y limitaciones.
